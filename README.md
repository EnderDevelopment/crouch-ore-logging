# Minecraft Fabric Mod: Crouch Break

Crouch Break is a Minecraft Java Fabric mod that adds controlled area breaking for logs and ores. When a player crouches while using an axe or pickaxe, the mod breaks matching blocks in a horizontal 3x3 area while preserving normal behavior for non-crouching actions, incompatible tools, and unrelated blocks.

## Install

1. Install Minecraft Java Edition 26.3.
2. Install Fabric Loader 0.20.1 or newer.
3. Install Fabric API for Minecraft 26.3.
4. Build or obtain the `crouchbreak-1.0.0.jar` file.
5. Place the JAR file in the Minecraft `mods` folder.
6. Launch Minecraft using the Fabric profile.

Requirements:

- Minecraft Java Edition 26.3
- Fabric Loader 0.20.1 or newer
- Fabric API
- Java 25 or newer

## Use

1. Hold any axe and break a log while crouching to break matching logs in a horizontal 3x3 area.
2. Hold any pickaxe and break an ore while crouching to break matching ores in a horizontal 3x3 area.
3. Use the correct tool for the target blocks. Blocks are only removed when the held tool is valid for their drops.
4. Break blocks without crouching to retain normal Minecraft behavior.
5. Non-matching blocks are left untouched.

The mod recognizes blocks in Minecraft's log and ore tags, including supported vanilla log types and ores such as coal, copper, iron, gold, diamond, emerald, lapis lazuli, redstone, and quartz when included by the relevant Minecraft tags.
